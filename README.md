# 技能熟练度追踪器

一个简单易用的技能熟练度追踪网站，帮助您记录和管理各种技能的熟练程度。

## 功能特点

- 用户注册和登录系统
- 自定义技能添加
- 精确到0.5的熟练度调整
- 直观的格子显示方式
- 数据自动保存
- 响应式设计，支持移动设备

## 使用方法

1. 注册账号
   - 点击"注册新用户"
   - 输入用户名和密码
   - 确认密码
   - 点击注册按钮

2. 登录账号
   - 输入用户名和密码
   - 点击登录按钮

3. 添加技能
   - 在输入框中输入技能名称
   - 点击"添加技能"按钮

4. 调整熟练度
   - 使用+1、+0.5、-0.5、-1按钮调整熟练度
   - 每个格子代表1个熟练度单位
   - 半格代表0.5个熟练度单位

5. 退出登录
   - 点击右上角的"退出登录"按钮

## 数据存储

- 所有数据都保存在浏览器的本地存储中
- 不同用户的数据相互独立
- 数据会自动保存，无需手动操作

## 技术栈

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 注意事项

- 请使用现代浏览器访问本网站
- 建议定期备份重要数据
- 清除浏览器数据会导致本地存储的数据丢失
